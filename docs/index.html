Connecting

No installation required — the server runs on Cloudflare's edge. Add it to any MCP-compatible client.

Claude Desktop — claude_desktop_config.json

JSON
{
  "mcpServers": {
    "job-boards": {
      "url": "https://job-boards-mcp.saba-dahboor.workers.dev/sse"
    }
  }
}

Claude Code (CLI)

Shell
claude mcp add job-boards --transport sse \
  https://job-boards-mcp.saba-dahboor.workers.dev/sse

Input Schema

All five tools share the same input parameters. title and location are required.

ParameterTypeConstraintsDescription
titlerequired string — Job title keyword — case-insensitive substring. E.g. "backend", "data engineer".
locationrequired string — City, country, or "remote". Country names are normalized to ISO codes ("United States" → US, "UK" → GB, etc.).
companyoptional string — Filter by company name substring. Omit to search all tracked companies.
daysAgooptional integer 1 – 365 Only include jobs published within this many days. Defaults to each tool's configured value.
limitoptional integer 1 – 100, default 20 Max results per page. Use with offset to paginate.
offsetoptional integer ≥ 0, default 0 Results to skip. Pass nextOffset from the summary to fetch the next page.

Response Format

Every tool returns two content items: a JSON summary and a Markdown table.

content[0] — Summary

JSON
{
  "title": "backend engineer",
  "location": "United States",
  "company": "all",
  "showing": "1–20 of 47",
  "companiesSearched": 120,
  "companiesWithMatches": 14,
  "daysAgo": 7,
  "runAt": "2025-10-18T09:42:11.000Z",
  "nextOffset": 20   // only present when more pages exist
}

content[1] — Markdown table

Columns vary by source — see each tool below. Returns No matching jobs found. when empty.

Publishing & Sharing

To make the server discoverable, submit it to one of these registries:

  • Smithery — most active MCP marketplace, web UI for submitting
  • mcp.so — community directory, submit via GitHub PR
  • modelcontextprotocol.io/servers — official curated list, PR to the modelcontextprotocol/servers repo

When sharing, always include the SSE endpoint URL and a config snippet so people can connect in one step.
